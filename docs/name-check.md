# Working-name check

Checked 6 October 2026 before the brand commit.

- **cairn.com is registered and in active use.** Verisign RDAP returns a registration dated 18 April 1995 and an expiration dated 19 April 2027. Its website is Douglas Goodwin’s portfolio.
- **Cairn.info is an established academic-publication platform.** Its site describes a digital library covering social sciences, science/medicine, and law. This is a related product category and a concrete potential naming conflict.
- A public trademark-index search was attempted but blocked (HTTP 403). An official jurisdiction-specific registration search and trademark clearance have **not** been completed. No claim of trademark availability is made.
- The user chose **“Cairn as working name”** after these findings were disclosed. The implementation uses this working name, with all editable branding in `src/lib/brand.ts`. No domain was purchased or asserted as available.

Sources:

- https://rdap.verisign.com/com/v1/domain/cairn.com
- https://cairn.com
- https://www.cairn.info

Before a public commercial launch, resolve the overlap with the academic platform and check relevant official trademark registries in the intended markets.
